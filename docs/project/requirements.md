
# Требования к системе

## User Stories

### US-01. Создание краткого пересказа

Как пользователь,
я хочу автоматически получать краткое содержание введённого текста,
чтобы быстрее знакомиться с основной информацией.

Критерии приёмки:

- система принимает исходный текст от пользователя;
- после обработки отображается краткий пересказ, сохраняющий основные мысли текста;
- если пользователь не ввёл текст, система выводит сообщение об ошибке.

### US-02. Выбор длины пересказа

Как пользователь,
я хочу выбирать степень сокращения текста,
чтобы получать пересказ нужного объёма.

Критерии приёмки:

- система предлагает три варианта длины пересказа: краткий, стандартный и подробный;
- пользователь может выбрать нужный вариант перед отправкой текста;
- система формирует пересказ с учётом выбранной степени сокращения.

### US-03. Копирование пересказа

Как пользователь,
я хочу копировать сформированный пересказ,
чтобы использовать его в своих заметках или документах.

Критерии приёмки:

- после формирования пересказа отображается кнопка «Копировать»;
- при нажатии кнопки пересказ копируется в буфер обмена;
- после успешного копирования система выводит уведомление.

## Use Case

### UC-01. Формирование краткого пересказа текста

**Актор:** пользователь.

**Цель:** получить краткое содержание исходного текста.

**Предусловие:** пользователь открыл страницу сервиса.

**Основной сценарий:**

1. Пользователь вводит текст в поле ввода.
2. Пользователь выбирает степень сокращения текста.
3. Пользователь нажимает кнопку «Создать пересказ».
4. Система проверяет наличие введённого текста.
5. Система передаёт текст и выбранную степень сокращения ИИ-модели.
6. ИИ-модель анализирует текст и формирует краткое содержание.
7. Система получает результат обработки.
8. Пользователь видит сформированный пересказ.

**Альтернативный сценарий:**

Если пользователь отправляет пустой текст, система выводит сообщение о необходимости ввода текста.

Если ИИ-модель не может обработать текст, система сообщает об ошибке и предлагает повторить попытку.

**Результат:** пользователь получает краткий пересказ исходного текста или сообщение об ошибке, если обработка невозможна.
