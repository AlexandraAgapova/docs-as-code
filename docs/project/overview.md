# Сервис автоматического краткого пересказа текста

## Описание проекта

Сервис автоматического краткого пересказа текста - приложение, которое использует методы искусственного интеллекта для создания краткого содержания текстовых документов.

Пользователь вводит текст, после чего система обрабатывает его с помощью языковой модели и формирует сокращённую версию с сохранением основных мыслей и ключевой информации.

## Основные пользователи

- Студенты - для сокращения учебных материалов и конспектов.
- Преподаватели - для получения краткого содержания учебных и научных текстов.
- Другие пользователи - для быстрого ознакомления со статьями и документами.

## Основные функции

1. Ввод и отправка текста для обработки.
2. Автоматическое формирование краткого пересказа с помощью ИИ.
3. Выбор степени сокращения текста.
4. Просмотр и копирование полученного результата.
